# suno-create

Panneau « Create » inspiré de Suno (modes Simple et Advanced), branché sur l'API Eleven Music d'ElevenLabs.

## Lancer

```bash
npm install
npx -y @elevenlabs/cli@latest onboard init   # crée la clé dans .env.local
npm start                                    # http://localhost:5340
```

L'API Eleven Music demande un forfait ElevenLabs payant.
